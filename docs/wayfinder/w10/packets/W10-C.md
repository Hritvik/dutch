# W10-C — Fixtures, harness and bundle pin

## Objective

Replace legacy fixtures with valid and forbidden-field fixtures for the new contracts, update the validation harness and pin the IAM bundle.

## Outputs and ownership

Own `contracts/**/fixtures/**`, `contracts/validate-contracts.mjs`, `contracts/test/**` and the imported bundle record. Do not change contract shapes without returning to A or B.

## Acceptance

- Every valid fixture validates; every forbidden-field fixture fails for the asserted reason (global identity, App Subject in HTTP, identifier, credential, token, undeclared field).
- The harness validates the new mapping event and profile HTTP surfaces only.
- The IAM bundle version and sha256 are recorded as immutable consumer input.

## Verification

```bash
cd contracts
npm test
npm run validate
```
