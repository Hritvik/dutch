# W12-A — Serve profile state and the profile split

## Objective

Add `GET /api/v1/me/profile-state` and make `/api/v1/me` return `409 profile_required` until the profile is ready, then the closed Dutch profile.

## Outputs and ownership

Own `services/ums/src/main/java/com/dutch/ums/profile/ProfileStateController.java` and its test. Do not edit the consumer or contracts.

## Acceptance

- `/api/v1/me/profile-state` returns `{data:{state,retryAfterSeconds?}}` with only the three permitted states.
- `/api/v1/me` returns 409 `profile_required` while required/provisioning, then `{data:{memberId,displayName,profileState,lifecycleState}}`.
- No response exposes App Subject, global identity, identifier, credential or token.

## Verification

```bash
./gradlew :services:ums:test --tests '*ProfileStateControllerTest'
```

## Handoff

- Current state: ready for the UMS agent; do not claim from the IAM session.
