# W10-B — Pin the Dutch profile HTTP contract

## Objective

Author `/api/v1/me/profile-state` and the profile-required/ready behaviour of `/api/v1/me` using the pinned IAM error envelope shapes.

## Outputs and ownership

Own `contracts/http/gateway/openapi.yaml`. Do not edit event contracts.

## Acceptance

- `GET /api/v1/me/profile-state` returns only `state` (`PROFILE_REQUIRED|PROFILE_PROVISIONING|PROFILE_READY`) and safe retry guidance.
- `GET /api/v1/me` returns `409 profile_required` until ready, then a closed Dutch Member Profile.
- No response exposes App Subject, global identity, identifier, credential, code or token.
- Correlation is the IAM `cor_` shape; errors use the pinned messages.
