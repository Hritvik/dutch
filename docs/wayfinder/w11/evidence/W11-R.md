# W11-R evidence — UMS slice review

Decision: approve

Findings: no critical/high/medium. All W-11 criteria are met: app-scoped schema with unique (app, subject), producer-keyed inbox with fingerprint and durable quarantine, idempotent consumer, exactly one profile/outbox per onboarding, emitted event validated against the pinned Dutch schema, transactional rollback proven through the Spring proxy, and a database-role negative proving UMS cannot connect to the IAM database.
