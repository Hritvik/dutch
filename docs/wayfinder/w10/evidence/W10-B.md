# W10-B evidence — Dutch profile HTTP contract

- Packet: `W10-B`
- Agent: `OPENCODE-DS41F`
- Date: 2026-10-31

## RED observed

The previous `/api/v1/me` returned `identityId, memberId, lifecycleState, mappingVersion` — a global identity leak
and no profile — and there was no `/api/v1/me/profile-state`.

## GREEN

- `contracts/http/gateway/openapi.yaml` now defines:
  - `GET /api/v1/me/profile-state` → `ProfileStateResponse` with only `state`
    (`PROFILE_REQUIRED|PROFILE_PROVISIONING|PROFILE_READY`) and optional `retryAfterSeconds`.
  - `GET /api/v1/me` → `409` `profile_required` until ready, then a closed `ProfileReadyResponse`
    (`memberId, displayName, profileState, lifecycleState`).
  - IAM-shaped correlation (`cor_`-compatible pattern) and paired error codes/messages, including the Dutch
    `profile_required` domain code.
- Verified by the W10-C harness (Swagger validation + fixtures).

## Acceptance mapping

| Criterion | Evidence |
|---|---|
| Profile state exposes only state + safe retry guidance | schema `additionalProperties:false`; two state fixtures |
| `/api/v1/me` 409 profile_required then profile | 409 ErrorResponse ref asserted; profile-ready fixture |
| No App Subject / global identity / identifier / token | `findProtectedHttpValues` test |
| Correlation and fixed errors | schema patterns and paired enum |

## Risks

- The Dutch profile body is Dutch-owned; `displayName` is the only free-text field and must stay bounded.

## Review 01 remediation

- **B-1 (medium) fixed**: the `409` response now references a dedicated `ProfileRequiredResponse` whose
  `error.code`/`error.message` are `const profile_required` / `Complete your profile to continue.`; a
  negative test proves a `not_found` body fails that schema.
- **B-2 fixed**: `ErrorResponse` now carries the optional allowlisted `details` array, and `PINNED.md`
  states the pinned shape accurately.
- **B-3 fixed**: both GET routes declare the optional bounded `X-Correlation-ID` request header.
- Harness now 10/10 with `npm run validate` clean.
- Note: the running UMS controller still returns the legacy shape; that is W-12 scope and W10-F must
  not be read as runtime compliance.
